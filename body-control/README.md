# 몸동작 조종

실행·배선·원점 복원은 [프로젝트 README](../README.md)를 참고합니다. 영상은 브라우저에서 처리하며 저장하거나 업로드하지 않습니다.

## 사용

1. 카메라를 켜고 양쪽 어깨와 앞으로 나란히 뻗은 팔을 보여 줍니다.
2. 처음 3초 안정 확인 후 자동으로 시작합니다. 실물은 USB·원점 PWM 준비 후 **실물 추종 대기**를 누릅니다.
3. 정상 종료는 **원점 복귀 후 OFF**입니다. `Space`/`Esc`로 멈추면 자동 재개도 해제됩니다.

## 기본 설정

| 항목 | 동작 |
|---|---|
| 몸 구간 | 다리 → 몸통 → 양팔을 세 링크에 대응 |
| 가려진 다리·허리 | 각각 수직 90° 가정 |
| 베이스 회전 | 거울 화면 오른쪽 45°가 중앙, 감도 1.5배, ±60° |
| 회전 고정 | 베이스 0°, 한쪽 어깨·손목으로 측면 2D 조종 |
| 짧은 인식 손실 | 0.8초 미만이면 자세 유지 후 즉시 재개 |
| 긴 인식 손실 | 가상 0.6초, 실물 별도 1.8초 안정 확인 |
| 실물 대응 | 저장한 수직 원점 기준 절대 관절각, 배율 1배 |
| 명령 범위 | 500~2500µs 및 원점 ±1000µs |
| 이동 상한 | V3 1,200µs/초, V2 1,000µs/초, 구형 100µs/초 |

양쪽 어깨 선의 3D 추정으로 방향을 계산합니다. 완전한 옆모습에서 어깨가 겹치면 회전 고정을 사용합니다. 인식 Hz·추론 시간과 실물 PWM 로그는 카메라 아래에 표시합니다. 카메라 없는 합성 시험은 실물로 전송하지 않습니다.

## 실물 명령과 한계

어깨=다리 절대각, 팔꿈치=몸통−다리, 손목 굽힘=팔−몸통입니다. 기본 환산은 11.111µs/°이며 실제 각도 센서값이 아닙니다. CH4는 원점 고정, CH5는 OFF입니다.

명령 경로는 최대 120µs 구간으로 나눠 검사합니다. MOVE가 350ms 끊기면 목표를 현재 출력에 고정하고, 통신이 2초 끊기면 PWM OFF입니다. 전원 차단 시 원점 복귀는 불가능합니다.

실물의 바닥·베이스·비인접 링크 간섭을 임시 치수로 검사합니다. 가상 팔은 별도의 설명용 치수를 사용하며, 가상 충돌에서 멈춘 관절각을 실물 목표로 유지합니다. 주변 물체·인접 브래킷·하중·처짐은 포함하지 않습니다. [치수 설정](DIMENSIONS.md).

로컬 라이브러리는 Three.js 0.180.0, MediaPipe Tasks Vision 0.10.32, Pose Landmarker Lite float16 v1입니다. `setup-assets.py`로 준비하며 다운로드 파일은 Git에서 제외합니다. D435i 깊이 입력은 구현하지 않았습니다.
