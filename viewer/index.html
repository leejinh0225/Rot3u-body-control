도 단위 조정 · 명령각

0–180° ↔ 500–2500µs로 환산합니다. 1° ≈ 11.1µs. 이 눈금은 조작용 가정이며, 실제 서보·관절 각도는 실측 보정해야 합니다. 각도 입력도 아래 관절 한계를 따릅니다.

출력 명령은 약 100µs/초로 목표까지 이동합니다. 100µs 변경은 약 1초이며 첫 출력에는 적용되지 않습니다. PCA 1카운트 ≈ 4.88µs이므로 5µs는 거의 1단계입니다. 실제 움직임은 데드밴드·기어 유격·하중에 따라 다릅니다.

팔이 처질 수 있습니다. 4선 방식은 I²C 단선 시 중지할 수 없으므로 PSU를 끄십시오.

관절별 조정 범위

기본 1000–2000µs

500–2500µs 안에서 시작값 1500µs를 포함하는 범위를 지정합니다. 숫자는 펄스 허용 범위이며 기구의 안전 가동범위가 아닙니다. 걸림 없이 확인한 구간만 조금씩 넓히십시오. 설정만으로 모터를 움직이지 않습니다. Uno 리셋 후 기본 1000–2000µs로 돌아오며 원점 파일 불러오기는 이 한계를 바꾸지 않습니다.

① 함께 켜기 → ② 관절 선택 후 도/µs 단위 조정 → ③ 실물 자세 확인 → ④ 원점 기록. 원점은 µs로 저장하며 기존 파일도 읽을 수 있습니다. 기록 버튼은 모터를 움직이지 않습니다. 기계적 수직·정렬은 눈금자·수평계 등으로 확인하십시오. 하중·유격은 원점 보정만으로 사라지지 않습니다. 기록은 같은 브라우저에 보관하며 아래 파일 저장으로도 남길 수 있습니다.

CH05만 움직이지 않을 때

다른 관절이 동작하면 PCA 전체 고장으로 단정할 수 없습니다. 현재 로그에는 CH05의 1500→1550µs 명령이 있으므로, 간섭·소음이 없다면 1500에서 감소 방향도 작은 단계로 확인하십시오. 전체 가동범위를 자동으로 훑지는 않습니다.

  1. 팔 전체를 받치고 PSU 출력을 끕니다. 3핀 방향, 한 칸 밀린 연결, 실물 CH5 인쇄를 확인합니다.
  2. CH4·CH5에 꽂힌 서보 플러그를 서로 바꿉니다. 전원이 켜진 채 뽑거나 꽂지 마십시오.
  3. 한 채널 시험으로 비교합니다. 문제 서보가 CH4에서도 안 움직이면 서보·케이블·그리퍼 기구 쪽이 의심됩니다.
  4. 정상 서보도 CH5에서만 안 움직이면 CH5 헤더·납땜·PWM 출력 쪽이 의심됩니다. 단순 I²C 정상 응답은 채널 출력 파형을 보증하지 않습니다.
  5. 교차 시험 후 PSU OFF에서 원래 배선으로 돌립니다. 배선을 바꾼 채 원점 기록이나 함께 켜기를 사용하지 마십시오.

사진만으로 혼 장착 오차와 설계상 각도를 구분할 수 없습니다. 심한 소음·걸림·발열·CC 표시가 있으면 PSU를 끄고 기구를 확인하십시오.

최초 구동

  1. PSU를 끄고 팔 전체를 지지합니다.
  2. Arduino IDE에서 ArmBench.ino를 열고 Uno·COM 포트를 선택한 뒤 → 업로드합니다.
  3. 시리얼 모니터를 닫고 이 화면을 새로고침합니다.
  4. USB 연결 후 「준비 · 출력 꺼짐」을 확인합니다.
  5. PSU 5.0V, 첫 단독 시험 약 1–2A 제한으로 시작하고 CH5를 ±5µs씩 관찰합니다.

CC 표시, 전압 강하, 심한 떨림·걸림이 생기면 즉시 PSU를 끄십시오. 코드에는 전류 센서가 없습니다.

전체 사용 안내서 · VCC와 V+를 연결하지 마십시오. PSU 주전원에는 짧고 굵은 전선을 사용하십시오.
